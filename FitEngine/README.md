# fit_engine — نظام تحديد ملاءمة الملابس واقتراح المقاس

الجزء الثالث من مشروع التخرج (منصة فلسطينية لتجربة الملابس افتراضيًا).
يستقبل قياسات جسم المستخدم وقياسات كل مقاس من قطعة الملابس، ويحدد المقاس الأنسب، ويوضح لكل منطقة إن كانت القطعة **ضيقة أو مناسبة أو واسعة**، ويقترح بديلًا عند الحاجة.

- يعمل **مستقلًا تمامًا** عن نظام الأفاتار ونظام إدارة الملابس.
- مكتوب بـ **Python 3.9+** (مُختبر فعليًا على Python 3.11.9 / Windows) ويستخدم **المكتبة القياسية فقط**: لا تثبيت، لا مكتبات خارجية، لا خدمات مدفوعة. الواجهة HTML/JavaScript بدون مكتبات وتعمل بدون إنترنت.
- الإصدار الحالي: **0.2.0** (ما تغيّر عن 0.1.0 في `docs/REPORT.md`).
- الوحدة الأساسية: **السنتيمتر**. يقبل أيضًا mm و m و in ويحوّلها تلقائيًا.

> ⚠️ النظام مختبر على **بيانات تجريبية فقط**. نجاح الاختبارات يعني أن المنطق يعمل كما صُمّم، ولا يعني أن التوصيات دقيقة على ملابس حقيقية. لم تُقس أي نسبة دقة حتى الآن.

## التشغيل

كل الأوامر تُنفّذ من داخل مجلد `fit_engine_project`.

المتطلبات: Python 3.9 أو أحدث فقط. **لا يوجد ما يُثبَّت** (لا `pip install`).

### 1. تشغيل الاختبارات
```bash
python -m unittest discover -s tests -t . -v
```
(على Windows إذا كان الأمر `python` غير معروف استخدمي `py`.)
النتيجة المتوقعة: `Ran 89 tests ... OK`. الاختبارات لا تحتاج أفاتار ولا ملابس ثلاثية الأبعاد ولا إنترنت (اختبارات الـ API والواجهة تشغّل خادمًا محليًا مؤقتًا على `127.0.0.1`).

### واجهة المستخدم
```bash
python -m fit_engine serve --port 8765
```
ثم افتحي `http://127.0.0.1:8765/` في المتصفح. أدخلي قياسات الجسم والمقاسات المتاحة واضغطي "احسب المقاس المناسب".
- كل نتيجة تظهر محسوبة فعليًا من `recommend_size` عبر `POST /recommend` (يظهر رقم إصدار المحرك أسفل النتيجة).
- زر "تعبئة مدخلات تجريبية" يملأ **المدخلات فقط**؛ النتيجة تُحسب دائمًا.
- قسم "إدخال JSON مباشر" يقبل مستندات بصيغة `docs/DATA_MODEL.md` مباشرة.
- الحقول الفارغة تُرسل كغير متوفرة؛ لا تُخترع قيم.
- قسم "تعبئة القياسات من الأفاتار" يقبل طلب أو رد `POST /generate-avatar` من موديول براءه (انظر `docs/INTEGRATION.md`).
- إذا كان المنفذ 8765 مستخدمًا (مثلًا Dress3D)، شغّلي على منفذ آخر: `python -m fit_engine serve --port 8020`.

### 2. توصية من ملفات JSON
```bash
# ملخص عربي مقروء
python -m fit_engine recommend --body examples/body_medium.json --garment examples/garment_tshirt_regular.json --summary

# النتيجة الكاملة بصيغة JSON
python -m fit_engine recommend --body examples/body_medium.json --garment examples/garment_tshirt_regular.json
```

### 3. API محلي
```bash
python -m fit_engine serve --port 8765
```
ثم:
```bash
curl -X POST http://127.0.0.1:8765/recommend -H "Content-Type: application/json" \
     -d '{"body": {...}, "garment": {...}}'
```
- `GET /health` فحص التشغيل
- `GET /schema` الأنواع والقصات والقياسات المدعومة
- `POST /recommend` التوصية (200 للنتيجة، 422 لمدخلات غير صالحة، 400 لطلب بشكل خاطئ)

### 4. من كود Python
```python
from fit_engine import recommend_size

result = recommend_size(
    {"unit": "cm", "measurements": {"chest": 92, "waist": 80, "hip": 96, "shoulder_width": 44}},
    {"category": "t_shirt", "fit_type": "regular", "stretch": "low", "unit": "cm",
     "sizes": [{"label": "M", "measurements": {"chest": 100, "shoulder_width": 44}},
               {"label": "L", "measurements": {"chest": 108, "shoulder_width": 46}}]},
)
print(result["recommended_size"], result["overall_fit"])
```

## مثال على المخرجات (ملخص)

```
✅ المقاس الموصى به: 32
تقييم الملاءمة: مناسب — الثقة: high
  • محيط الخصر: جسم 80.0 / قطعة 81.0 → فرق +1.0 (المطلوب -5.6..+3.0) = مناسب
  • محيط الورك: جسم 96.0 / قطعة 97.0 → فرق +1.0 (المطلوب -5.7..+7.0) = مناسب
السبب: القماش مطاطي (medium)، لذلك يُسمح بأن تكون القطعة أصغر من الجسم بحدود 7% في المحيطات.
بديل: المقاس 30 بديل لمن يفضّل قصة أكثر إحكامًا.
```

المزيد في `examples/outputs/`.

## أنواع الملابس المدعومة حاليًا

| النوع | `category` | القياسات الأساسية | القياسات الثانوية |
|---|---|---|---|
| تيشيرت | `t_shirt` | الصدر، الكتفين | الخصر، الورك |
| قميص | `shirt` | الصدر، الكتفين | الخصر، طول الكم، الورك |
| جاكيت | `jacket` | الصدر، الكتفين | طول الكم، الخصر، الورك |
| فستان | `dress` | الصدر، الخصر، الورك | الكتفين |
| بنطلون | `pants` | الخصر، الورك | الفخذ، طول الساق الداخلي |
| تنورة | `skirt` | الخصر، الورك | — |

إضافة نوع جديد (مثل الثوب الفلسطيني أو العباية) = إضافة سطر في `CATEGORY_RULES` و `BASE_EASE` في `rules.py` + اختبار.
