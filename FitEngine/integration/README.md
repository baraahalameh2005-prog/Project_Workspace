# زر «اقترح لي مقاسًا» في صفحة الأفاتار — اقتراح لبراءه

**مُطبَّق** على فرع `integrate-fit-engine` بعد موافقة براءه (2026-10-17). الملف `avatar_page_size_button.patch` يبقى مرجعًا للتغيير وللتراجع عنه.

## ماذا يفعل
- يضيف زرًا تحت زر «إرسال الأفاتار إلى غرفة القياس»، بنفس الشكل (`transfer-button`).
- عند الضغط: يتحقق أن خدمة المقاسات تعمل (`GET http://127.0.0.1:8020/health`)، ثم يفتح صفحة FitEngine مع
  **القياسات التي أدخلها المستخدم** في الرابط:
  `http://127.0.0.1:8020/?avatar_id=<id>&height=163&chest=88&waist=72&hip=100` (+ `shoulder` إن وُجد).
- صفحة FitEngine تعبّئ قياسات الجسم منها تلقائيًا؛ المستخدمة تدخل مقاسات القطعة وتحسب.
- قبل إنشاء أي أفاتار، أو أثناء الإنشاء، يعرض رسالة بدل أن يفتح شيئًا.

## ما لا يغيّره
- **0 أسطر محذوفة، 75 سطرًا مضافًا** في `App.tsx` فقط (5 مواضع).
- لا تغيير في الـ backend، ولا في الـ API، ولا في `api.ts` أو `savedAvatar.ts` أو `AvatarViewer.tsx`.
- لا يرسل قياسات الموديل المتولّد (`measurements.*`) ولا الوزن.
- عنوان الخدمة قابل للتغيير بـ `VITE_FIT_URL` (مثل `VITE_CLOTHING_URL`).

## التطبيق والتراجع
من جذر المشروع:
```
git apply FitEngine/integration/avatar_page_size_button.patch
```
والتراجع:
```
git apply -R FitEngine/integration/avatar_page_size_button.patch
```
يجب تشغيل FitEngine على المنفذ 8020: `cd FitEngine` ثم `python -m fit_engine serve --port 8020`.
